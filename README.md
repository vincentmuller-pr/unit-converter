# Unit Converter

A simple web application for converting values between different units.

## Features

* Length conversion
* Weight conversion
* Temperature conversion

## How to use

Clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/vincentmuller-pr/unit-converter
cd ./unit-converter
```

Then open `index.html`.

## Purpose

This project was created as a learning project to practice frontend development, DOM manipulation, forms, JavaScript modules, and responsive CSS.
